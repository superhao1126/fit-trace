# 循形 UI 重设计任务书

日期：2026-10-10。用户反馈：现有 UI 不够精美，页面缺少统一标准，基础控件混用；首页 DiaryDateStrip 尤其需要重设计。本文件记录设计目标与第一版 Figma 交付状态。

设计文件：[循形 · 统一设计系统与核心页面](https://www.figma.com/design/Ct4AworB8fYBPjpSVwWbRW)。

## 首个设计对象：日记首页与日期选择

首页以记录为主，日期控件不应占据两层独立工具栏。标题显示所选日期语义，例如“今天”或“10月9日”，副标题补充星期和年份。标题右侧设置明确的日历图标按钮；查看历史日时显示“回到今天”。

标题下方为可横向滑动、按周定位的七日日期栏。取消独立的上一周/下一周箭头与单独月份工具行。星期为辅助信息，日数为主要信息；选中日期使用实色品牌底和相应前景色。今天但未选中、选中、普通、未来禁用、键盘焦点各自有明确状态。今天标记不能与“已有记录”标记混用。

点击日历按钮打开统一底部弹层月历。弹层包含月份切换、周一至周日的月网格、所选日期与今天状态；未来日期不可选。点击有效日期后关闭弹层并更新日记；取消或返回关闭时保留原选择。弹层使用组件库的遮罩、焦点与关闭机制，日期网格为复用的业务组件。禁止以透明原生 date input 覆盖月份文字作为入口。

390px 为主要设计画布，并检查 320px：七个日期触点不少于 40px 宽，交互区高不少于 44px。横滑外仍提供日历按钮和键盘导航入口。跨周、跨月、跨年、今天在周首/周中/周末均需要设计状态和行为。

## 统一规范

1. 颜色：背景、表面、文字三级、边界、品牌色和状态色统一为语义变量；浅色/深色分别定义。松针绿作为第一版品牌候选，用高保真首页验证实际效果。
2. 排版：页面标题、区块标题、主要数值、正文、辅助说明固定层级；字号、字重、行高不由每页独立决定。
3. 布局：统一 4px 间距基准、24px 页面边距、卡片/行/表单间距与圆角；图标统一现有图标库与尺寸。窄屏边距需在实现时验证并适当收紧。
4. 状态：按钮、字段、日期、导航均覆盖默认、按下、选中、禁用、加载、错误与焦点；页面覆盖空数据、错误与重试。
5. 信息密度：以清晰标题、数据层级和精确留白组织页面；卡片只用于有明确分组意义的内容，不把每个字段包成一张卡。

## 组件与代码规则

保留现有 TDesign Mobile Vue 作为基础，不引入第二套基础组件库。设计完成后建立项目级 UiButton、UiField、UiSheet、UiTabs、UiPageHeader 等公共接口，统一主题、尺寸和状态，底层复用 TDesign；页面通过公共接口使用基础控件。

周历、日记行、图表摘要等业务组件可以自定义，但必须使用公共样式变量与基础控件。禁止在页面中重新实现基础按钮、弹窗或字段皮肤，禁止页面通过深层选择器各自改组件库内部样式。文件选择 input 等平台接入控件允许作为业务组件的内部实现。

组件规范明确区分操作按钮、导航行、日期格与表单字段，避免把不同语义都包装成同一种大按钮。公共组件在源码与 Figma 中使用一致的名称与变体。

## Figma 交付范围

- Foundations：语义颜色、文字、间距、圆角、图标和深色变量。
- Components：基础控件及周日期栏、月历弹层、记录行的变体与状态。
- 首批高保真页面：日记首页、月历弹层、饮食录入、档案、趋势、我的。
- 原型：周日期切换 → 月历选历史日期 → 补记 → 返回所选日期。
- 开发映射：组件名称、变量名称、尺寸和布局规范，支持后续统一改造。
