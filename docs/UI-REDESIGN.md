# FitTrace 页面与流程改造计划

日期：2026-10-10。参考案例 A、B、C，并以当前四类记录为基础。

## 本轮范围

保留松针绿、四个主导航、二级页返回、深浅模式及现有数据。通过统一日期入口、紧凑行布局和确认流程完善已有功能，不新增会员、社区、课程或大型依赖。

1. 精简：添加记录页只负责新增；首页只保留一个档案入口；我的改为档案入口与目标；显示模式并入设置；移除未使用的悬浮按钮代码。身体历史隐藏空指标，管理操作进入详情。
2. 日期日记：首页周历与日期选择，选中日期的身体、饮食、训练和照片概览，带日期补记并返回；列表 API 增加日期范围，档案按月查询与继续加载，支持筛选和选日补记。
3. 输入流程：饮食识别结果可一次核对名称、份量和热量，文字纠正按需展开，避免重复加入；照片先本地预览，确认角度、日期与备注后上传保存，支持分页浏览。
4. 数据解释：去掉默认减 3 kg 和默认 90 天期限；设置目标不隐式写入体重。修正跨模块统计的日期口径、单日体重变化和热量文案；详细统计保持按需展开。
5. 验证：格式、Lint、类型、H5/API 构建、相关服务回归；通过独立内存 API 页面检查 390px、320px、深浅模式、空/有数据、日期切换、补记返回及照片确认。真实 AI、邮件、数据库与 APK 验收独立记录。
