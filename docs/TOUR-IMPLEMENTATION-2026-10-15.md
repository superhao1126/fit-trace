# Tour 漫游式引导实现

2026-10-15。按已确认的 [Tour V2 设计](./TOUR-V2-2026-10-15.md) 接入现有页面。

## 已实现

- 首页 4 步、模板 2 步、训练记录 4 步、饮食新增 3 步。使用页面中的 `data-tour` 锚点，不复制页面或创建教程页。
- 原生模态 dialog 保持底层页面不可交互；SVG 蒙层挖空高亮，气泡指向目标，支持上一步、下一步、跳过、关闭和 Escape。Android 返回键优先关闭 Tour。
- 气泡在目标上下自动调整，监听页面滚动、窗口、可视区和目标尺寸变化。目标消失时跳过对应步骤；数据加载时先等待目标，不把空白当作目标。
- 状态保存到当前设备，按账号、引导版本和模块隔离；跳过与完成都会停止重复展示。引导状态与饮食、训练草稿分开保存。
- 2026-10-15 中国时间起创建的账号自动展示模块首次引导；更早账号不被强制打断，可从「我的 → 设置 → 重新查看功能引导」开启。该入口返回首页，其他模块在实际进入时展示，不替用户开始训练。
- 查看引导仅介绍功能，不会执行开始训练、勾选完成、AI 分析、记录保存等业务操作；正常训练页面自身已有的计时和草稿机制保持原行为。
