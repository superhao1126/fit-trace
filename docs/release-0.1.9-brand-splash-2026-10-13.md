## 旧发布链接修复与清理

发布预检发现上一轮版本清理遗漏了跨版本链接：0.1.8 的 apps/api 与 deploy 链接指向已删除的 20261012-bcbe53e。初次发布被文件预检阻止，当前运行进程未停止。

从本地保留的原正式发布包恢复 API，90 个编译 JS 文件与当前 API 逐文件一致。API 运行包固定在 /opt/fittrace/runtime/api-bcbe53e/api，当前及回滚版均链接到此稳定目录；两版的 deploy 文件独立保存。没有 API 业务改动或数据库迁移。

清理脚本增加删除前链接校验：失效链接、指向待删除发布目录的链接都会阻止清理。独立临时目录测试覆盖旧目录依赖拒绝、稳定目录依赖通过、失效链接拒绝。

本次删除 0.1.7 发布目录和旧完整备份，只保留 0.1.9、0.1.8 和本次发布前完整备份。清理后重新启动 API 并再次执行真实 smoke，验证稳定运行包可独立启动。
