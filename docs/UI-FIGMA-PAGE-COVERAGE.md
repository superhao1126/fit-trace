## 视觉约定

- 页面底色 `#F1F3F5`，内容卡片白色，正文 `#202824`，辅助文字 `#727C77`。
- 品牌绿 `#26735B` 用于主操作与选中态；身体蓝、饮食橙、训练紫、照片青绿用于分类提示。
- 图标采用圆头、圆角连接的统一线性风格；表单、按钮、筛选、卡片沿用一致的圆角与间距。
- 主要设计宽度 390；完整首页、趋势、档案及协议按滚动内容绘制长页面，常规页面高 844。
- 数据、邮箱、版本及照片均为设计示例；照片采用可编辑矢量占位示意。验证码挑战保留第三方服务容器，不模拟其实际题目。
