## TDesign UniApp 落地

用户最终指定腾讯组件库，采用适配现有 Vue 3 / uni-app 工程的 `@tdesign/uniapp@1.0.0`，未采用面向聊天场景的 MiniProgram Chat。已实现对应八个画面、统一安全区导航和四项底栏，以及动作选择、计划选择、体重录入、详情修改、删除和退出弹窗。训练与体重记录接入原接口，示例数据仅位于隔离视觉检查副本。

Figma MCP 配额不足后按用户授权，通过 Chrome 打开本文件查看总览及放大的登录/今日设计；结合此前保存的图层与布局数据实施。微信开发者工具实看发现 Grid 统计布局异常，已换为 Flex；训练组输入也采用 Flex。计划列表收紧为 48px 行，个人菜单收紧为 40px 行；固定训练保存和体重入口不随列表滚走。详情提供紧凑摘要及按组展开，保留实际记录查看能力。

按用户最新反馈，登录表单不再插入红色错误文字；校验、请求失败和发送成功均采用微信原生 Toast，不改变表单高度。

构建、全仓类型检查、小程序 ESLint、Oxlint、13 项小程序测试和本轮文件格式检查通过。开发者工具中的登录后检查使用独立临时视觉副本，未验证真实收信、真机或真实账号操作，也未上传发布。

最终已关闭隔离预览并切回仓库内正式工程；在空邮箱状态点击“获取验证码”，开发者工具实际显示微信原生 Toast“请输入正确的邮箱地址”，表单没有插入错误行。未发送邮件。
