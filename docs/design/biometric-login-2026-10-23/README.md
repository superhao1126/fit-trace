# 指纹登录设置与首页登录 · 2026-10-23

[Figma 主稿](https://www.figma.com/design/Ct4AworB8fYBPjpSVwWbRW?node-id=257-8000) · [完整设计页](https://www.figma.com/design/Ct4AworB8fYBPjpSVwWbRW?node-id=257-4365) · [本机点击预览](http://127.0.0.1:4186)

设计交付包含 16 个状态各自的 390/320px、浅/深色版本，共 64 个 SVG；Figma 另有四张主稿的审阅总览。示例邮箱不代表真实用户资料。后续 Android 实现与验证见 [IMPLEMENTATION.md](IMPLEMENTATION.md)，H5/API 未改动。

## 页面调整

- 设置页：标准返回顶栏 → 指纹状态概览 → 当前账号与本机开关 → 分组使用说明。开关是唯一开通入口；移除开发用的“重新检查”“移除凭据”等常驻操作。
- 首页登录页：延续当前品牌绿、循形插画和白色登录容器，显示脱敏账号，突出“指纹登录”，下方保留“使用邮箱登录”。首次安装、没有本机账号时，直接使用现有邮箱登录。
- 邮箱回退：验证码表单、密码切换和协议沿用既有功能。空表单的主按钮禁用；输入、协议勾选与可提交态在实际组件中处理。本原型的输入仅为静态示意。
- 默认状态只呈现用户需要的操作；重试出现在错误说明中。检查失败和开通结果待确认时，开关显示省略状态，避免把未知状态表示为“关闭”。

## 视觉与组件约定

沿用 `docs/design/final/theme-tokens.json` 和 Android `FitTraceTheme`：背景 #F7F8FA、白卡、品牌绿 #24C867、深色 #111713 / #1D2620；字体延续设计稿 Noto Sans SC，Android 实现使用系统字体。

| 元素 | 约定 |

| 布局 | 16px 页面边距；组内 16px；分组间距 24px 起；长内容随页面滚动 |
| 字号 | 页面标题 18；主标题 21–27；主操作 15；正文 13–14；辅助 11–12 |

## 交互和状态

开通：点击开关 → 最近身份验证仍有效时直接调用系统验证；需要补充验证时进入邮箱验证码页 → 系统验证成功并确认服务端开通结果后才打开开关。取消回到原状态。验证码页主稿展示静态输入位，原型中的继续按钮仅演示路由。

关闭：点击已开启开关 → 确认框 → 服务端撤销成功后关闭；取消保持开启；失败保留已开启状态并给出重试反馈。关闭不会退出当前会话。普通退出登录保留本机独立登录凭据。

登录：已绑定账号 → 指纹按钮 → 系统验证 → 成功进入现有首页。取消停留在登录页；网络失败允许显式重试；锁定期间禁用指纹，邮箱入口可用；凭据失效时邮箱变为主操作，登录后在设置重新开启。移除本机账号是失效恢复操作，实际接入时复用现有移除确认框，不与服务端关闭混用。

系统验证窗是示意，不作为应用自行绘制的弹窗。登录与开通应分别传入对应的系统标题和说明；指纹位置、传感器样式、错误与锁定反馈由 Android BiometricPrompt 决定。本机允许的有效强生物识别均可能通过，文案不承诺绑定某一枚指纹。

16 个状态为：设置未开启、设置已开启、指纹登录、邮箱回退、按需邮箱验证、验证码错误、系统验证示意、关闭确认、尚未录入、设备不支持、检查失败、开通结果待确认、取消登录、网络失败、凭据失效、系统锁定。初始检查和请求中的加载态实现时复用共享加载反馈；不得闪现确定的开关状态或允许重复提交。
