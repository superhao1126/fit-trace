## 本轮训练设计

| 画面 | 节点 | 行为约定 |
| --- | --- | --- |
| 训练入口 | 193:4153 | 快速记录与逐组训练分开进入；提供复用最近训练入口 |
| 快速记录 | 193:4229 | 名称、类型、时长与开始时间；热量、备注为次要信息 |
| 逐组训练 | 193:4282 | 查看上次训练、标记完成组、休息时间、添加动作与暂停 |
| 核对保存 | 193:4340 | 汇总实际完成内容，允许返回继续训练 |
| 首次使用 | 194:4278 | 没有记录时提供直接记录入口，不强制先建模板 |
| 加载中 | 194:4368 | 保留页面结构，使用占位，避免显示虚构记录 |
| 保存中 | 194:4440 | 禁止重复提交，等待接口完成 |
| 保存失败 | 194:4503 | 保留输入，明确重试入口 |

画面数据为固定示例，按钮和表格展示用于设计讨论，尚未接入真实 API，也尚未完成点击原型连线。训练功能范围参照现有 H5 的 WorkoutFormView 与 TrainingSessionView；只统计已完成组，未知热量不转为零。

已检查图层结构：388 个后代节点，包括 113 个文字节点、53 个组件实例；没有整屏位图，字体为 Noto Sans SC。Figma MCP 额度用尽后，通过内嵌编辑器检查八屏全貌，并修正快速记录字段的默认示例与快速记录/逐组训练的内容间距。初稿预览见 [训练八屏](fittrace-training-green-2026-10-19.png)。当前仍是设计初稿，320px 窄屏、数字键盘及点击原型需在后续批次补齐。
