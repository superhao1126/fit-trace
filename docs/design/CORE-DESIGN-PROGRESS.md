## 最新训练交互方向：参考 CalJimi（2026-10-19）

用户要求按上次查看的 CalJimi 交互重排。当前主方案为 [34 / 运动记录 · CalJimi 参考交互](https://www.figma.com/design/Ct4AworB8fYBPjpSVwWbRW?node-id=196-4365)，下方 33 号八屏保留为旧交互草稿。主流程改为「记录列表 → 选择运动 → 填时长或距离 → 加入清单 → 完成记录 → 返回列表」，逐组力量训练降为单独次要入口。

- 左侧分类、右侧项目，顶部搜索、自定义与 AI 速记入口。
- 点击项目后在底部弹层调整日期、时长或距离，配数字键盘；确认加入已选清单，尚不视为完成记录。
- 底栏汇总项目数与消耗，可展开清单修改或移除，再统一完成记录。
- 新增六屏：空记录、运动库、时长输入、连续选择、已选清单、保存后的列表。
- 参考证据：[CalJimi v3.0 截图集](https://uinotes.com/app/750953113823751436?ocr=%E8%BF%90%E5%8A%A8)、[时长/距离键盘](https://uinotes.com/pin/908622033270149694)、[已选清单](https://uinotes.com/pin/182809938483481014)。交互顺序据截图序列推断，未操作真实 App；不能据截图确认实际持久化时机、换算算法或错误处理。
- Figma MCP 额度已用尽，通过编辑器导入 SVG 原生文字和矢量图层，并检查六屏全貌。该批导入尚未绑定组件/变量、自动布局或点击原型连线；后续实现前需补齐。

本轮只修改设计和设计记录，没有修改 H5、Android 或 API。热量为固定示例估算；距离换算、运动数据来源、AI 与自定义细则需单独确认，不能直接使用截图数值作为生产算法。

## 本轮训练设计

| 画面 | 节点 | 行为约定 |
| --- | --- | --- |
| 训练入口 | 193:4153 | 快速记录与逐组训练分开进入；提供复用最近训练入口 |
| 快速记录 | 193:4229 | 名称、类型、时长与开始时间；热量、备注为次要信息 |
| 逐组训练 | 193:4282 | 查看上次训练、标记完成组、休息时间、添加动作与暂停 |
| 核对保存 | 193:4340 | 汇总实际完成内容，允许返回继续训练 |
| 首次使用 | 194:4278 | 没有记录时提供直接记录入口，不强制先建模板 |
| 加载中 | 194:4368 | 保留页面结构，使用占位，避免显示虚构记录 |
| 保存中 | 194:4440 | 禁止重复提交，等待接口完成 |
| 保存失败 | 194:4503 | 保留输入，明确重试入口 |

画面数据为固定示例，按钮和表格展示用于设计讨论，尚未接入真实 API，也尚未完成点击原型连线。训练功能范围参照现有 H5 的 WorkoutFormView 与 TrainingSessionView；只统计已完成组，未知热量不转为零。

已检查图层结构：388 个后代节点，包括 113 个文字节点、53 个组件实例；没有整屏位图，字体为 Noto Sans SC。Figma MCP 额度用尽后，通过内嵌编辑器检查八屏全貌，并修正快速记录字段的默认示例与快速记录/逐组训练的内容间距。初稿预览见 [训练八屏](fittrace-training-green-2026-10-19.png)。当前仍是设计初稿，320px 窄屏、数字键盘及点击原型需在后续批次补齐。
