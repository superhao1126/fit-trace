# 下拉刷新设计

[Figma：18 · 下拉刷新](https://www.figma.com/design/Ct4AworB8fYBPjpSVwWbRW?node-id=92-240)。

参考用户指定的乐刻当前页面，并在手机上执行一次下拉、截图及短录屏观察：内容保持原位，圆形指示器随手势下移，松手后上移收回。本设计将该交互用于首页、趋势、档案，使用循形现有品牌标、绿色及深浅主题颜色。场景里的记录数据均为示例。

## 视觉

- 圆形底座 48px，品牌标约 22px，外环直径 36px、线宽 2px；主题表面色底，轻微下方阴影。
- 品牌标来自 UiBrandMark 的现有 SVG 路径。品牌标保持稳定；刷新中外环旋转，品牌点沿用呼吸动效。
- 浅色绿色 `#26735B`；深色品牌绿使用浅绿色，底座与深色表面协调。
- 字体使用 PingFang SC，与现有中文 Figma 设计一致。
- 默认不占页面高度、不移动内容、不显示常驻刷新文案。

## 状态与操作

1. 待机：隐藏指示器。
2. 下拉中：在顶部出现，随距离下移并逐渐显现；未达到阈值松手即取消。
3. 达到阈值：外环进度完整，松手触发一次请求。
4. 刷新中：回到顶部固定刷新位置，外环旋转，等待真实请求完成；不切换整页 loading 或骨架屏。
5. 收回：上移淡出，建议 180ms；成功直接更新数据，无成功 Toast。
6. 失败：收回指示器，保留旧内容，沿用现有错误提示。

建议初始手势阈值为 72px，指示器最大位移 88px，带阻尼；数值需在实现及用户真机体验时调节，不视为已测定的乐刻参数。仅在实际滚动容器顶部响应。横向日期条、图表拖动、弹层打开及请求进行中不触发重复刷新。减少动态偏好下禁用循环动画，保留静态状态和可访问说明。

## 三页刷新范围

- 首页：更新当前选中日期的概览和记录，保留日期。
- 趋势：更新图表、统计、分析，保留时间范围和指标。
- 档案：更新当前日期范围下的最新记录并重置分页，保留月份、日期及记录类型；并发加载更多需在实现时处理。

## 交付边界

Figma 通过内置浏览器导入 SVG，文字及矢量分层可编辑；属于固定布局的状态设计稿，尚未制作可播放的交互原型或绑定变量的组件变体。源 SVG 和 Figma 预览保存在本目录。

## 实现与验证

- `UiPullRefresh` 接入首页、趋势、档案：只移动浮层；松手刷新，未达到阈值取消；请求中禁用重复触发；取消手势、多点触摸及缓存页离开时清理监听和状态。
- 48px 底座、22px 品牌标、外环动画和 180ms 收回；通过现有主题变量适配深浅色和减少动态设置。
- 只在文档滚动顶部响应；横向滚动容器、输入、趋势图表和可见模态弹层不触发；阻止浏览器原生下拉刷新竞争。提供键盘可聚焦的刷新按钮和状态播报。
- 三页保留筛选和已有内容，档案刷新第一页；趋势请求加入顺序校验，避免旧请求覆盖新范围，刷新失败仍显示旧图表。
- 5 项独立手势测试覆盖阈值、短下拉、方向锁定、回拉取消、资格变化、阻尼上限和取消。
- 内置浏览器使用实际页面与组件、模拟 HTTP 和触摸事件验证：非顶部不触发、短下拉取消、横向/输入/弹层/图表不触发、内容原位、请求去重、首页更新和失败保留、趋势保留 30 天范围及失败时的图表、档案四类请求重置至第一页及失败保留记录。
- 390px 浅色和 320px 深色检查通过，指示器 48px、品牌标 22px，无横向溢出；实现预览见本目录 `fittrace-pull-refresh-light-2026-10-13.png` 和深色对应文件。
- `pnpm check`、关闭源映射上传的前后端构建、176 项 API/H5 测试通过；部署脚本语法检查通过。仍有原有 `UiInput.vue` 属性顺序警告和趋势图表包体超过 500kB 的非阻断构建提示。本地 HTTP 测试解除沙箱端口限制后通过。
- 临时预览已移除；本轮没有调用真实业务接口、操作手机、发布或安装 APK。用户真机验收重点：下拉手感、阈值、系统状态栏安全区、弱网收回与图表手势。
