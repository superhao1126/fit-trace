# 基础组件与品牌加载

设计：[15 · 基础组件与品牌加载](https://www.figma.com/design/Ct4AworB8fYBPjpSVwWbRW?node-id=83-113)。先完成可编辑设计画面，再接入代码。设计包含底部弹层、普通/危险确认、数字输入、页面/按钮加载及深色状态；导入画面采用固定布局。

- UiBrandMark / UiLoading：循形 F + 圆点，F 保持稳定、圆点轻跃；遵循减少动态设置。页面加载期间隐藏内容但保留组件状态，加载结束恢复。首页和个人页原有骨架屏继续保留。
- UiButton 与登录提交按钮：共用品牌加载标识、继承按钮颜色；提交中由原有按钮行为禁用重复点击。
- UiBottomSheet：统一标题、关闭、底部操作区、安全区、内容滚动、键盘焦点与 Escape；食品库、动作详情接入。
- UiNumberInput：直接输入、单位、整数提示与上下限错误提示，不强制把清空值变为 0；食品份量、训练次数/重量/休息接入。step 保持原字段配置，不自动截断小数。
- UiConfirmDialog / confirmDialog：统一普通和危险确认，提交中禁用确认/取消；由调用方在成功后关闭，失败时保留弹窗重试。身体、饮食、训练、照片删除与训练完成确认接入。

## 验证

通过内置浏览器的独立组件预览验证：320px 数字范围提示与清空；食品库浏览、0 克禁止加入、150 克正常确认；底部弹层关闭；确认提交中禁用操作、模拟失败保留、重试成功关闭；浅色与深色品牌加载。

以上为组件级验证，未调用真实删除或保存接口。手机 WebView 的输入键盘、手势滚动、底部安全区及实际网络加载仍由用户真机验收。未部署、未打包 APK。
