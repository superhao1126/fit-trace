# 循形品牌开屏

设计：[16 · 品牌开屏](https://www.figma.com/design/Ct4AworB8fYBPjpSVwWbRW?node-id=89-175)。先完成可编辑画面，再实现 Android 原生窗口与 WebView 启动衔接。普通 H5 浏览器不显示品牌开屏。

视觉采用松针绿 #26735B、白色 F + 圆点图标、中文名称「循形」与宣传语「记录每一次改变」。静态开屏写入 index.html，默认隐藏；只在 Capacitor 原生环境中显示。原生桥接已就绪时首帧即可呈现，main.ts 的原生初始化同时提供兜底，普通 H5 直接进入页面。

- 首个路由和登录恢复就绪后渲染页面，在下一绘制帧移除开屏；没有固定停留时间或倒计时。
- 会话、自动续期、登录跳转与深链接继续沿用原逻辑；页面间跳转和 App 回前台不重新展示开屏。
- 开屏期间浏览器主题色、Android 系统栏和 WebView 底色使用品牌颜色；退出后恢复当前主题。
- 路由初始化失败时移除开屏并提供重新加载入口。
- Android 配置品牌启动图标与底色，兼容旧系统的窗口背景。Android 12+ 原生系统启动屏先展示图标，WebView 首帧再补上中文名称与宣传语，采用[官方启动屏主题机制](https://developer.android.com/develop/ui/views/launch/splash-screen)。

## 验证

320px 内置浏览器核对全屏布局；直接打开真实应用时先观察到品牌画面，路由完成后开屏节点与启动标记均移除。当前已有会话的本地域进入 /dashboard，独立未登录域进入 /login，浏览器主题色恢复正常。开发 API 不可用时首页显示已有失败重试状态，这不影响开屏退出验证。

13 项登录会话回归、类型检查、修改文件 Lint 与 H5/正式 Android 构建通过。保留原有 Gradle 弃用提示。本轮未发布新版、未安装或操作手机。

## 真机验收

1. 彻底退出后冷启动：系统图标 → 中文品牌画面 → 首页/登录页，是否有白闪或图标跳动。
2. 已登录、未登录和离线启动；品牌画面不增加固定等待时间。
3. 浅色/深色主题、系统状态栏与底部手势区的颜色衔接。
4. 页面跳转和从后台回前台不重复出现开屏。
