# 国内常见食物扩充候选目录

2026-10-16。18 类、360 项候选，不等于 360 条已验证营养记录；不直接导入运行时食品库。

现有 H5 库共 141 条，按主食26、蔬菜32、水果15、肉蛋奶24、水产11、豆类坚果27、零食饮品6分类，来源为 USDA SR Legacy。Android 与 H5 独立客户端，后续应从统一数据资产生成各端资源，不能仅修改 H5 就声称 Android 已支持。

## 来源优先级

1. 基础食材：优先中国疾控营养与健康所/中国营养学会食物成分查询平台与《中国食物成分表》可使用版本；逐项核对来源、版本、编码、生熟、可食部、单位和使用权限。
2. 品牌/连锁食品：优先国内厂商、餐饮品牌官网或当前包装营养标签；具体到产品、规格与版本。不是使用通用条目冒充品牌实测。
3. 中式复合菜：优先国内实测/研究或获许可数据库；缺少实测时使用有配方与重量依据的计算值，并显著标识估算。
4. 国内商业平台作为补充候选，核对授权范围、原始来源与更新机制后接入；USDA 等只在国内缺项时作为明确标注的补充。

## 入库与展示规则

- 菜单分类是便于查找的产品分类，保留原始数据分类，二者分别存储；“我的常用/收藏/自定义”是动态入口，不算食物分类。
- 别名只用于搜索；红薯/地瓜等可关联同一条，生米/熟饭、干木耳/泡发木耳等不能合并营养值。候选名称不代表新增净条数，需与现有141条去重、补全、替换映射。
- 米面基础食物按原料与生熟标明；水饺标馅料；麻辣烫/冒菜/香锅优先拆配料；奶茶须匹配品牌、杯型、糖量、加料，不能给所有变体一个固定数字。
- 每条至少记录来源机构、记录ID、引用URL/书目页码、版本/更新日期、原始名称、计量基准、核验状态；热量/营养/照片来源独立。
- 保留kJ与kcal的原始单位及转换记录；100g、100mL和每份不能直接混用。克重不从“碗/个/勺”字面猜测。
- 未核验数值保持null；展示“待补充”，不提供虚假精确换算。不能把候选记录当作已核验项加入统计。
- 实物缩略图用对应真实食物摄影；禁止生熟错图、不同食物共用角色插画。缺图不挪用不相干照片。角色插画只用于入口与提示。
- 旧ID、用户收藏和历史营养快照保留；同名源切换不能回写历史记录。
