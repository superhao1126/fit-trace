# 原生 Android 运动记录

对照 Figma `Ct4AworB8fYBPjpSVwWbRW / 196:4795` 的选择、时长、连续添加、清单核对流程实现。沿用运动工具入口，支持搜索、自定义、修改、移除、日期与时间、保存失败重试、详情编辑与删除确认。力量训练记录编辑保留原有动作和组数据。

- API 逐条保存清单；每次成功响应后从待保存清单移除，失败保留剩余项。未知热量传 null，未使用设计样例中的热量常数。服务端未提供距离字段，因此目前仅记录实际分钟，未添加无法持久化的公里入口。
- 未添加尚无真实能力支撑的 AI 速记和常用列表。这里不宣称运动设计全部状态已完成。
- 六张实拍图复用仓库 `docs/design/sport-photos` 中的原始设计资产，分别用于相同运动的 42dp 圆角缩略图。摄影来源与许可见该目录 README.md / sources.json；Android 资源名为 `sport_*`。
- Robolectric 交互覆盖明确保存、历史日期、未知消耗、失败保留、移除、部分失败重试与详情删除确认；390 浅色、320 深色截图位于 `feature/main/build/reports/workout-screenshots`。验证不代表真实账号 API 或手机验收。
