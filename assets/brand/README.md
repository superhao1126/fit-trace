# 循形Fitness

产品名称：**循形Fitness**；简称可使用“循形”（xún xíng）。循着每天的记录，看见身体的变化。「循」对应持续记录与轨迹，「形」对应身体状态与体形。

图形以圆角字母 F 和一个独立的轨迹节点组合，呼应 Fitness 的英文首字母与记录定位。主色采用松针绿，保持现有产品克制、清晰的风格。

## 素材

| 文件                               | 用途                                               |
| ---------------------------------- | -------------------------------------------------- |
| `app-icon-1024.png`                | 1024 × 1024 App 图标，完整方形画布；圆角由平台处理 |
| `app-icon-master.png`              | 1254 × 1254 生成母版                               |
| `logo-transparent.png`             | 1124 × 440 透明 PNG，中英文品牌组合，用于浅色背景  |
| `logo-dark-presentation.png`       | 2172 × 724 深色背景展示版 PNG，带背景，不是透明图  |
| `favicon.ico`                      | 包含 16、32、48、64、128、256 像素 PNG 帧的 ICO    |
| `favicon-16.png`、`favicon-32.png` | 浏览器 PNG 图标                                    |
| `apple-touch-icon.png`             | 180 × 180 iOS 网页收藏图标                         |
| `preview.html`                     | 用浏览器打开即可查看实际素材及小尺寸效果           |

设计参考色：松针绿 `#2F7D5B`、暖白 `#F7FAF5`、文字深灰绿 `#202923`；深色展示版使用薄荷绿 `#67CDA3`。生成图像存在轻微像素色差，以随附 PNG 为最终视觉稿。本套交付为位图，不含可编辑矢量源文件。

## 项目接入

- 网页标题使用「循形Fitness」，favicon 与收藏图标位于 `apps/h5/public`。
- 登录页、关于页和应用显示名称统一使用「循形Fitness」。
- 通用图标与 Logo 母版保留，供后续独立 Android 客户端复用。

图标主体位于中央安全区域。使用时保持宽高比，不拉伸、不为应用图标预先添加外部圆角，不将深色展示版误当作透明 Logo。

## 生成记录

使用 Codex 内置 `image_gen` 生成图形与 Logo，随后仅裁去透明留白、缩放并封装 PNG/ICO。提示词见 `PROMPTS.md`。生成母版保留。

公开检索发现已有同名英文健康产品 [FitTrace](https://www.fittrace.com/)。本方案保留用户给定英文名；正式品牌注册前需要另行核查名称与图形，当前检索不代表商标可用性确认。

品牌名称已统一为「循形Fitness」。历史设计稿、含 FitTrace 字样的 PNG 组合标识及生成提示词保留作归档，不作为当前品牌展示素材；现行客户端使用 F 图标与可编辑文字组合。代码包名、应用 ID、仓库名及部署地址沿用原有技术标识。
